
# MiniTienda – Registro y Análisis de Ventas

## Descripción
Programa desarrollado en Python para registrar y analizar ventas
de una pequeña tienda.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib

## Funcionalidades
- Registro de productos y stock
- Registro de ventas
- Descuento del 5% desde 10 unidades
- Generación de CSV
- Cálculo de métricas
- Gráfico de ingresos
- Registro de errores en log.txt

## Retos
- Reto A: Producto nuevo
- Reto B: Exportación PNG
- Reto C: Descuento
- Reto D: Registro de intentos fallidos
